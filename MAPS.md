## 🔐 File Integrity Verification

Each map includes a SHA-256 checksum to help verify that the downloaded file has not been modified or corrupted.

### How to verify a file on Windows

1. Download the map from this repository.
2. Open Command Prompt (`cmd`).
3. Navigate to the folder containing the downloaded file.
4. Run the following command, replacing the filename with your actual file name:

```cmd
certutil -hashfile "your-file.rbxl" SHA256
```

5. Compare the resulting hash with the SHA-256 value listed in the catalog.

If the hashes match, the file matches the version listed in this catalog.
